## 实测结果与边界

- Qwen3.5 完成 240/240 次公开测试调用，无传输错误。信息不足题严格拒答 **59/60**；可回答题答案关键词匹配 **127/180**，严格“答案 + 源文引用 + 完整证据”联合通过 **72/180**。
- 联合分数不是语义正确率：完整长引文、单位别名和标点要求会误伤正确答案。报告保留 11 个选定错误案例的分析，也记录了真实的 Coverage B 错答和把美元免赔额问题回答成百分比的失败。
- 在全 65 来源检索中，最初的混合检索完整证据率是 **114/180（63.33%）**，开启候选图关联降至 **113/180（62.78%）**。不能宣称图越大越好。
- 六条真实引用的探索性版本：关闭图 **63.33%**，明确引用图 **63.33%**。这不是新增的独立留出测试。
- 合成图实验中，完整证据从 **24/72** 提升至 **72/72**；它验证短小明确引用链上的机制，不能写成真实保险问答准确率 100%。
- 两个本地环境均通过 **236 项测试 + 52 项子测试**。新增入口沿用现有网页 demo，原始生成、引用、拒答和历史实验记录均保留。

## 使用

解压 `InsureRAG-VLM_Graph_Research_20261001.zip`，在项目根目录按 README 安装依赖。`python scripts/demo_source_linked.py` 启动扩展语料 demo，默认是明确标注的 CPU 基线。使用实际 Qwen：

```powershell
python scripts/demo_source_linked.py --vlm-model ollama:qwen3.5:4b --expected-digest 2a654d98e6fba55d452b7043684e9b57a947e393bbffa62485a7aac05ee4eefd
```

需要本地 Ollama 服务（默认端口 11435）和对应模型；添加 `--retrieval-model C:/models/bge-small-en-v1.5` 使用真实 BGE。权重、运行环境和生成索引不在代码包内。说明、重现实验命令和完整指标见仓库 `docs/GRAPH_RESEARCH_PROTOTYPE.md` 与 `reports/graph_research_v1/RESULTS.md`。

项目已具备可复现实验、来源追溯、图消融和失败案例，适合称作研究原型。当前仍不能声称真实保单上 GraphRAG 已显著胜出；需要更多带可靠条款关系的实际公开保单与批单，以及独立领域审阅。HNSW 可留作未来的规模/速度对照，不是这一轮的核心。

本轮未修改 A/B Testing 项目或简历文件，也未向 GitHub 推送。之前的交付包仍保留。
