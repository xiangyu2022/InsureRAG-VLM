## 完成条件

声明证据映射检查一题的全部声明原文范围能否定位到准入来源的固定分块；不证明这些范围都是回答必需的。
必要支持标注检查题目实际要求、证据和答案关系、计算及限制条件，并保存能覆盖必要单元的替代分块组合。
答案附加说明不会自动成为强制评分金标。拒答题只记录缺失事实及诊断上下文，不设可回答题的检索金标。
两层均不等于全局验收；审阅由单一 Codex 流程执行，不称专家或人工审阅。
