## 测试集如何扩大

新增 [InsuranceQA V2 作者发布的基准](https://github.com/shuzi/insuranceQA)，包括 **27,413 条答案、2,000 道验证题和 2,000 道测试题、12 个保险领域**。另保留 12,889 道原始训练题供查重；本轮没有用这些题训练模型。

4,000 道验证／测试题全部跑完：BM25、BGE、混合 RRF 三组，分别检索全量答案和原始候选池，合计 **24,000 次排序评测**。未把正确答案人工补入检索候选。

原来的 **240 道 Qwen 生成测试**单独保留。本轮新增 2,000 道是答案检索测试，不能说成新增 2,000 道经过验证的生成式保险问答，也不据此提高 Qwen 的准确率。真实条款的专家复核、多证据问答和拒答基准仍需要进一步建设。

另新增 **171 个真实跨页导航案例：17 开发、154 测试**，按计划家族分开。它们直接来自不同源页的真实引用，测试从已知段落找到目标页。该诊断的标签与图关系共用提取规则，不能当成独立的图抽取准确率，更不能冒充 171 个理赔推理案例。

## 实测结果

| 2,000 道测试题，搜索全部 27,413 条答案 | Hit@1 | Hit@10 |
| --- | ---: | ---: |
| BM25 | 23.00% | 48.25% |
| BGE-small-en-v1.5 | 34.45% | **67.50%** |
| BM25 + BGE（RRF） | 31.40% | 62.95% |

BGE Hit@10 的标签分组 bootstrap 95% 区间约 **65.48%–69.55%**。这组结果不支持“混合检索一定更好”。搜索仍是精确向量检索，本轮没有添加 HNSW，也没有声称测得其加速收益。220 条长答案超过 512 tokens，被按固定协议截断。

原始 SOLR 候选池中有 256 道测试题没有标注正确答案，评测保留全部 2,000 题作为分母。发现 8 道题与训练／验证题文字重复；进一步用字符 n-gram 相似度 ≥0.92 标出 476 道近似题。原始分数保留，另报告剔除后的 1,524 题切片：BGE Hit@10 为 **68.77%**。这只是文字相似度敏感性分析，不宣称完成了语义去重；模型预训练是否接触过数据也未知。

154 个导航案例中，固定 3 页上下文时，目标页命中率为 BM25 **51.95%**、图扩展 **65.58%**、按文字中的印刷页码直接查找 **96.75%**。所以，明确页码引用优先直接解析有充分理由；复杂图遍历不能仅凭“保险有关系”就认定更优。最早一次开发评测误把标准目标页作为直接查找结果，已标为无效并保留原记录；修正后的结果明确标作探索性诊断。

对扩大到 73 份文档的语料，再运行原有 240 道题的全局检索回归：在 180 道有答案题上，关闭图时完整证据进入上下文的比例为 **64.44%**，开启显式图为 **63.33%**。这是旧问题面对更多干扰文档的检索检查，不是新增的独立测试题，也没有调用生成模型。

- 完整环境 **250 项测试 + 52 项子测试通过**；最小环境 **247 项通过、3 项可选依赖测试跳过、52 项子测试通过**。
