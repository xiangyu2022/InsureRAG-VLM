# 任务、指标与结果口径

项目有两个核心任务：检索证据，以及根据证据生成最终回答。检索再分为相关内容排序与多条证据完整检索。BGE、BM25、RRF、reranker 和图检索是方法，不是另外五个任务。

| 评测线 | 已有指标 | 后续实验建议的 primary |
| --- | --- | --- |
| 保险 FAQ 相关内容排序 | Hit@1/10、MRR@100、nDCG@10 | nDCG@10，以保险 FAQ 为主评估集 |
| 多条证据完整检索 | Complete-evidence@5/10、Evidence Recall@5 | Complete-evidence@5 |
| 最终回答 | 答案键命中、严格答案/来源/完整引文联合检查、拒答、回答覆盖率 | 经语义评审的 Grounded Answer Accuracy；尚未完整测量 |

## nDCG@10 是什么

nDCG@10 衡量前十条检索结果的相关程度和排序。相关结果越靠前，贡献越大；以该问题的理想排序归一化后，再对所有问题取平均。当前数据使用二元相关标签，不是人工评定的多级相关性。

对第 i 个结果，相关时 rel_i=1，不相关时为 0：

```text
DCG@10  = sum(rel_i / log2(i + 1), i=1..10)
nDCG@10 = DCG@10 / IDCG@10
```

IDCG 是把所有标注相关结果放到最前面时的理想得分。评测题应有至少一个标注相关结果；无标注题的处理必须事先声明。

若某题只有一条标准相关答案，排第一得 1，排第三得 0.5，排第十约得 0.289，前十没有它则得 0。多条相关结果会共同贡献得分。Hit@10 对第一和第十都只记一次命中，MRR 只使用第一条相关结果的位置。

保险 FAQ 的 nDCG@10：公共 BGE-small 为 0.438029，上轮流程为 0.525496，本轮为 0.529632。它不是 52.96% 的最终回答正确率。本轮相对上轮的变化也是描述性补报，不能事后声称模型按此主指标选出。

## 完整证据与最终回答

Complete-evidence@5 是前五条结果包含全部标注证据的题目比例。FinQA 的 1,147 题上，上轮为 64.52%，本轮为 72.45%。这是给定年度报告范围的证据检索；没有执行数值程序，也不等于 GraphRAG 的收益。原始证据标注可能包含冗余表头，因此严格标注完整性不等于最小充分语义证据。FAQ 的多个标准答案往往可以互相替代，不能把它们都解释成必须找齐的事实。

建议后续最终回答主指标为：结论正确、关键条件完整、关键断言受到实际提供并引用的证据支持的题数，除以全部可回答题数。可回答却拒答计为失败；证据不足题的正确拒答率作为单独约束。评分标准应在新评测前固定，并进行盲化人工复核；自动裁判需要独立校准。

现有 240 题 Qwen 历史测试含 180 道可回答题和 60 道证据不足题：答案键命中 127/180，严格答案/来源/完整引文联合检查通过 72/180，严格拒答 59/60。严格合同通过率 40% 不是语义正确率，也不能由此推导 60% 幻觉率。最新检索模型没有在该集合重新执行端到端回答评测。

## 已完成实验与后续建议的区别

本轮训练前锁定的选择目标是保险 FAQ、FiQA、政府和通用域的加权 MRR@100，加上 FinQA 完整证据@5，并设置回退约束。上面的单主指标设计适用于下一轮预先声明的实验，不替换已有协议。历史测试已经多次查看，下一轮需要独立测试；不同数据域不合并成一个准确率。
